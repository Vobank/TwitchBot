# Твич-бот · TwitchBot

**[Русский](#русский) · [English](#english)**

> 🌐 **Язык интерфейса: только русский** · **Interface language: Russian only**

Бот для Twitch-чата: модерация, команды, таймеры и приветствия — плюс веб-панель для управления.

A Twitch chat bot: moderation, commands, timers and greetings — plus a web panel to manage it.

---

## Русский

### Что это
Подключается к вашему Twitch-чату и автоматизирует рутину: банит спам, отвечает на команды, шлёт таймерные сообщения и приветствует зрителей. Управление — через веб-панель.

### Возможности
- 🛡 Модерация (спам/ссылки/правила)
- 💬 Пользовательские команды
- ⏲ Таймеры (периодические сообщения)
- 👋 Приветствия зрителей
- 🖥 Веб-панель управления

### Требования
- Python 3.12
- OAuth-токен Twitch (нужен для входа бота)

### Запуск
- `Твич-бот.bat` — запуск бота и панели

---

## English

### What it is
Connects to your Twitch chat and automates routine: bans spam, answers commands, sends timed messages and greets viewers. Managed via a web panel.

### Features
- 🛡 Moderation (spam/links/rules)
- 💬 Custom commands
- ⏲ Timers (periodic messages)
- 👋 Viewer greetings
- 🖥 Web control panel

### Requirements
- Python 3.12
- A Twitch OAuth token (needed for the bot to log in)

### Run
- `Твич-бот.bat` — start the bot and panel

---

### Технологии / Tech
Python · twitchio (v2) · веб-панель / web panel

### ⚠️
OAuth-токен задаётся локально и в репозиторий не входит. / The OAuth token is set locally and not included in the repo.
